## Install

Ask Codex to install the skill from https://github.com/LIghtJUNction/android-app-development, or run:

```sh
python ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo LIghtJUNction/android-app-development --path . --name android-app-development
```

The skill will be available on your next Codex turn. Invoke it with `$android-app-development`.
